# Cursor Mod

Un proyecto para crear un cursor personalizado global en Windows, sin depender de una página web.

## ¿Qué hace?

- Oculta el cursor del sistema
- Dibuja un cursor personalizado encima de la pantalla
- Permite cambiar entre varios estilos
- Funciona como una capa global del mouse en todo el sistema

## Estilos incluidos

1. Default
2. Crosshair
3. Neon
4. Pixel
5. Magic
6. Circle

## Uso

1. Instala Python 3.10+
2. Ejecuta:
   python main.py
3. Usa:
   - ESC para cerrar
   - 1 a 6 para cambiar estilo

## Nota importante

Es un cursor visual global sobre la pantalla y no un driver del sistema. Es ideal para personalización y prototipos visuales.
